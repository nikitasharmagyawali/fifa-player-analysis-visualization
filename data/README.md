## Data Sources

This project uses the FIFA 23 Official Dataset (2017–2022) from Kaggle: https://www.kaggle.com/datasets/kevwesophia/fifa23-official-datasetclean-data


- **FIFA 23 Official Dataset – Clean Data**  
  Combined player attributes and ratings from multiple FIFA editions (2017–2022) used for feature engineering, clustering, and outlier detection.

Raw data files are not included in this repository.
Data cleaning and preprocessing were performed in Python prior to unsupervised analysis in Python and Orange Analytics.
